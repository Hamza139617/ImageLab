Project Title: IMAGELAB	

Development environment: Microsoft Visual Studio latest version

Programming Language : C++

Project description:
This is an image processing application with the help of which you will be able to process your images.
You would be able to perform all of the operations including cropping, rotating, resizing , bucketfill  and many more.
All of these operations were implemented mainly through array.
You will also be able to undo and redo operations and also queue some operations.
The undo and redo operations were implemented through stack and the queued operations were implemented through the queue

Requirements:
For this project you would only be needing the stb_image header file and also the stb_image write header for writting into and 
reading from an image and placing the pixel data into the array and taking that data and placing it into the image.
but Not worry because i will already include these two header files in the project.

Building and running:
It is super easy and if you want to check the tests then you should just go to the tests folder , exlude the other mains only one main can exist in the project or else you are going to be recieving a 
linked error. 
perform the tests and if you want to have the overall demo run the source.cpp file and for testing run the files in the tests folder

Features:
1- loading image.
2- cropping image.
3- rotating image.
4- resizing image.
5- flipping image.
6- bucket fill
7- greyscale
8- saving
9- exporting
10- undo, redo, queue jobs or operations
11- brightening image.
